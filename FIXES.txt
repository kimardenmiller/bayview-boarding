  that anon no longer had. See git commit c77e87b.

  policy, meaning anyone with the public anon key (shipped in the JS bundle)
  could read/edit/delete every client's name, phone, email, signature, and
  health/aggression notes with an unauthenticated request. Locked to
  anon-INSERT-only; admin reads and returning-client lookup now go through
  Edge Functions (admin-data, lookup-client) using the service role key.
  Admin password moved from a hardcoded App.js constant to a Supabase
  secret, checked server-side. Old password rotated (was public in git
  history).
